Ravara — privacy

Ravara is a private dashboard used only by its owner.

Data

Vehicle and device data is fetched from the manufacturers' APIs and stored only on the owner's own computer. It is not sent to any third party, and no analytics or tracking are used, including on this website.

This website

These pages exist only to meet API registration requirements. The login page shows a one-time code to the owner in their own browser and does not transmit or store it.

Access

Access to a vehicle can be withdrawn at any time from the manufacturer's account settings.
